UI and UX design documentation for the cotel dashboard. These documents define the information architecture, page layouts, component library, design tokens, and wireframes.

| [Components](./components) | Shared UI component catalogue |
| [Design Tokens](./tokens) | Color, spacing, typography, and radius tokens |
| [Wireframes](./wireframes) | Low-fidelity wireframes for all dashboard pages |
| [FLO-8 Wireframes](./FLO-8-wireframes) | Wireframes from FLO-8 design iteration |
